# MSBench

Official repository for **Know Where You Stand: Memory-Source Choice in Long-Context Dialogue Agents** (NeurIPS 2026).

**Caishen Zhou, Yihong Tang, Xuefeng Bai, Kehai Chen, Min Zhang**  
Harbin Institute of Technology, Shenzhen

MSBench evaluates whether dialogue agents should rely on visible recent context or retrieve prior memory. MSR is our training-free method for this source-choice decision.
